## ADDED Requirements

### Requirement: System can guide users through aftersales processes
The system SHALL guide users through return, refund, and exchange processes with clear step-by-step instructions.

#### Scenario: Guide user through return process
- **WHEN** user wants to return a product
- **THEN** system SHALL provide step-by-step return instructions
- **AND** list conditions for eligible returns

#### Scenario: Explain refund policy
- **WHEN** user asks about refund policies
- **THEN** system SHALL explain refund eligibility criteria
- **AND** provide estimated refund timeline

#### Scenario: Guide user through exchange process
- **WHEN** user wants to exchange a product
- **THEN** system SHALL provide exchange instructions
- **AND** mention any additional costs or requirements

#### Scenario: Handle defective product returns
- **WHEN** user reports a defective product
- **THEN** system SHALL provide instructions for defective product returns
- **AND** offer replacement or repair options

### Requirement: Aftersales handler provides accurate process information
The system SHALL provide aftersales process information that is consistent with company policies.

#### Scenario: Consistent return policy
- **WHEN** users ask about return policies
- **THEN** system SHALL provide consistent and accurate information
- **AND** reference official return policy documents

#### Scenario: Return eligibility check
- **WHEN** user inquires about return eligibility
- **THEN** system SHALL list eligibility criteria
- **AND** explain how to check if their product is eligible
