# RagService Specification

## Interface Definition

### 1. RagService Interface

**Path**: `src/main/java/com/example/staffagent/service/RagService.java`

```java
package com.example.staffagent.service;

import com.example.staffagent.dify.dto.DifyResponse;

import java.util.List;

public interface RagService {
    String generate(String query, List<DifyResponse.Record> records);
    String generateWithQuery(String query);
}
```

### 2. RagServiceImpl Implementation Class

**Path**: `src/main/java/com/example/staffagent/service/impl/RagServiceImpl.java`

#### Dependency Injection

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class RagServiceImpl implements RagService {
    
    private final DifyKnowledgeBaseService knowledgeBaseService;
    
    @Value("${rag.prompt-template:}")
    private String promptTemplate;
    
    @Value("${rag.max-records:3}")
    private Integer maxRecords;
    
    @Value("${rag.max-content-length:2000}")
    private Integer maxContentLength;
    
    @Value("${agent.api-key:}")
    private String apiKey;
}
```

#### Core Methods

**generate(String query, List<DifyResponse.Record> records)**

```
Function: Generate response based on user question and knowledge base records

Input:
  - query: User question
  - records: Knowledge base retrieval records list

Output:
  - String: Response generated by large model

Process:
  1. Validate if records is empty
  2. Take first maxRecords records
  3. Convert records to JSON format
  4. Replace placeholders in Prompt template
  5. Call large model to generate response
  6. Return generated result
```

**generateWithQuery(String query)**

```
Function: One-stop RAG retrieval and generation

Input:
  - query: User question

Output:
  - String: Response generated by large model

Process:
  1. Call knowledgeBaseService.retrieveRecords(query)
  2. If there are results, call generate(query, records)
  3. If no results, return empty string
```

#### JSON Conversion Method

```java
private String recordsToJson(List<DifyResponse.Record> records)
```

Convert records to JSON string in the following format:

```json
[
  {
    "content": "text content",
    "score": 0.85,
    "document_name": "document name",
    "keywords": ["keyword1", "keyword2"]
  }
]
```

#### Prompt Replacement Method

```java
private String buildPrompt(String query, String context)
```

Replace `{{query}}` and `{{context}}` placeholders with actual values.

## Configuration Items

| Configuration Item | Default Value | Description |
|--------------------|---------------|-------------|
| `rag.prompt-template` | (See design document) | RAG Prompt template |
| `rag.max-records` | 3 | Maximum number of records to return |
| `rag.max-content-length` | 2000 | Maximum characters per record |
